📝 小红书笔记内容提取工具

简单3步,提取你小红书笔记的完整内容

💡 提示: 本工具需要在小红书已登录状态下使用

📋 第一步: 准备笔记链接

  1. 打开 小红书官网 并确保已登录
  2. 访问你的笔记列表或直接打开任意一篇你的笔记
  3. 复制需要提取内容的笔记链接(URL)

🔧 第二步: 打开开发者工具

  1. 在笔记页面按 F12 键(或右键点击→检查)
  2. 切换到 Console(控制台) 标签页
  3. 复制下面的脚本并粘贴到控制台
(async function() { console.log('📝 开始提取笔记内容...\n'); setTimeout(() => { const titleEl = document.querySelector('[class*="title"], h1, h2'); const title = titleEl ? titleEl.innerText.trim() : '未找到'; const contentSelectors = [ '[class*="note-text"]', '[class*="desc-text"]', '[class*="content-text"]', 'section[class*="note"] div[class*="text"]', 'article[class*="note"]', 'div[class*="rich-text"]' ]; let content = ''; for (const selector of contentSelectors) { const elements = document.querySelectorAll(selector); if (elements.length > 0) { const texts = Array.from(elements).map(el => el.innerText.trim()) .filter(t => t && t.length > 20).join('\n\n'); if (texts.length > content.length) content = texts; } } const imgElements = document.querySelectorAll('img'); const images = Array.from(imgElements).map(img => img.src) .filter(src => src && src.includes('sns-webpic')).slice(0, 9); console.log('标题:', title); console.log('URL:', window.location.href); console.log('\n内容:\n', content); console.log('\n图片:', images); }, 2000); })();

📥 第三步: 复制提取结果

  1. 脚本会自动在控制台输出提取的内容
  2. 复制输出的内容,粘贴到下方文本框
  3. 点击"保存到本地"按钮下载
