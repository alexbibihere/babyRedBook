```
1. 下载安装 Umi-OCR
```

## 步骤 1: 下载 Umi-OCR

### 方式 A: 直接下载 (推荐)

1. 访问 GitHub Releases:
   ```
   https://github.com/hiroi-sora/Umi-OCR/releases
   ```

2. 下载最新版本:
   - 文件名: `Umi-OCR_release_vX.X.X.7z`
   - 平台: 选择 Windows x64

3. 解压到任意位置:
   ```
   D:\Umi-OCR\
   ```

### 方式 B: 使用包管理器

```bash
# 使用 Scoop
scoop bucket add extras
scoop install umi-ocr

# 使用 Winget
winget install Umi-OCR
```

---

## 步骤 2: 批量识别图片

### 2.1 启动 Umi-OCR

双击运行 `Umi-OCR.exe`

### 2.2 切换到批量任务模式

点击左侧菜单的 **"批量任务"**

### 2.3 添加图片文件夹

1. 点击 **"添加文件夹"**
2. 选择路径:
   ```
   D:\迅雷下载\XHS-Downloader_V2.6_Windows_X64\_internal\Volume\Download
   ```
3. 确认添加了 206 张图片

### 2.4 设置识别参数

**识别语言**:
- 选择: **"简体中文"**
- 如果图片中有英文,选择: **"中英混合"**

**预处理选项** (推荐全部启用):
- ✅ 预处理 - 提高识别准确率
- ✅ 方向修正 - 自动旋转图片
- ✅ 排版分析 - 保持原有格式

### 2.5 开始识别

1. 点击 **"开始识别"**
2. 等待处理 (预计 5-15 分钟)
3. 实时查看进度条

### 2.6 导出结果

识别完成后:

**导出为 JSON** (推荐):
1. 点击 **"导出"**
2. 格式选择: **JSON** 或 **JSONLines**
3. 保存到:
   ```
   d:\github\babyRedBook\data\umi-ocr-result.json
   ```

**或者导出为 TXT**:
1. 格式选择: **TXT**
2. 保存到同一位置

## 💡 使用技巧

### 提高识别准确率

1. **选择正确的语言**
   - 纯中文: 简体中文
   - 中英混合: 中英混合
   - 有数字: 保持原样

2. **启用预处理**
   - 自动降噪
   - 自动二值化
   - 提高清晰度

3. **方向修正**
   - 自动识别图片方向
   - 修正倾斜角度

### 批量处理技巧

1. **分批处理**
   - 如果内存不足,分批处理 50-100 张

2. **后台运行**
   - Umi-OCR 可以在后台运行
   - 不影响其他操作

3. **保存进度**
   - 避免中途关闭
   - 导出前确认全部完成

## 🔧 常见问题

### Q1: Umi-OCR 无法启动?

**A**:
- 确保下载了 Windows x64 版本
- 解压到非中文路径
- 右键"以管理员身份运行"

### Q2: 识别结果不准确?

**A**:
- 启用"预处理"选项
- 选择正确的识别语言
- 确保图片清晰度足够

### Q3: 处理速度太慢?

**A**:
- 检查是否有其他程序占用 CPU
- 关闭不必要的后台程序
- 考虑分批处理

### Q4: 导出的 JSON 格式不对?

**A**:
- 确保选择了正确的导出格式
- 检查文件是否完整
- 重新导出一次
